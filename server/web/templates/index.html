{# ---- the one rule. this is the interesting part, so it goes first ---- #}

“nobody has rated this yet.”

there is no catalog here. no scraped database of every song ever pressed, no empty pages with a zero on them. a song gets an entry the moment a human stops and judges it — and if the last person who stood behind it takes their verdict back, it goes away again.

which means every page on this site is one somebody actually cared about. and when you're the first, the widget says so, and the credit stays yours as long as you stand behind it.

{# ---- the trace: the screenshot that travels ---- #}

the trace

while a track plays, a needle draws the shape of it. stamp a verdict and the line freezes onto the card — the actual waveform of the twelve seconds you made your mind up in.

honestly: this only happens when listening is switched on, which is off by default. no capture, no trace — an invented one would make the honest ones worthless.
